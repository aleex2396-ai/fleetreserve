# Prior looks

Every look at any data used here before the tag `frozen-plan`, recorded before WP1. Later looks are added with their commit.

## Summary

Held-out data is kept for the final run and never read row by row before it. Training data fits the forecast models; development data is used to choose settings; context sources hold no charging data. A work package (WP) is a numbered build step; a unit is a site or group of sites; the dial is the driver-risk setting; kappa is the forecast caution level; the gate is WP6's go or no-go test; tiers A and B are the driver-protected and deadline-contract readings. Held-out files were downloaded unparsed and hashed as bytes; the Norway split counted held-out rows by site (12,184) without printing a row; the Korean authors' scripts' aggregates were seen; no held-out row was printed; the Norway split program parsed the combined Norway file to separate the sites.
